# Preset Examples

This directory contains examples of configurations generated by each preset option in ai-rulez.

## Available Presets

Presets are tool-specific configurations that automatically set up the appropriate output files and directories for each AI tool.

### Claude Preset (`--preset claude`)

```bash
ai-rulez init "MyProject" --preset claude
```

**Generated outputs:**
- `CLAUDE.md` - Main Claude configuration file
- `.claude/agents/` - Directory for Claude agent files

**Features:**
- Includes Claude-specific agents (code-reviewer, test-writer)
- Optimized rules for Claude's capabilities
- Claude-specific instructions and best practices

See: [claude-preset.yaml](./claude-preset.yaml)

### Cursor Preset (`--preset cursor`)

```bash
ai-rulez init "MyProject" --preset cursor
```

**Generated outputs:**
- `AGENTS.md` - Shared configuration (also used by AMP and Codex)
- `.cursor/rules/` - Cursor-specific rules in MDC format

**Features:**
- Cursor IDE integration guidelines
- Multi-file editing best practices
- Context management instructions

See: [cursor-preset.yaml](./cursor-preset.yaml)

### Windsurf Preset (`--preset windsurf`)

```bash
ai-rulez init "MyProject" --preset windsurf
```

**Generated outputs:**
- `.windsurf/` - Directory-based rules (new format)

**Features:**
- AI-native development guidelines
- Natural language code generation tips
- Windsurf-specific features and workflows

See: [windsurf-preset.yaml](./windsurf-preset.yaml)

### GitHub Copilot Preset (`--preset copilot`)

```bash
ai-rulez init "MyProject" --preset copilot
```

**Generated outputs:**
- `.github/copilot-instructions.md` - Repository-wide Copilot instructions

**Features:**
- Copilot usage guidelines
- Security considerations for generated code
- Best practices for effective suggestions

See: [copilot-preset.yaml](./copilot-preset.yaml)

### Gemini Preset (`--preset gemini`)

```bash
ai-rulez init "MyProject" --preset gemini
```

**Generated outputs:**
- `GEMINI.md` - Google Gemini configuration

### Multiple Tools Preset

You can also combine multiple tools:

```bash
ai-rulez init "MyProject" --preset claude --preset cursor --preset copilot
```

Or use specific flags:

```bash
ai-rulez init "MyProject" --claude --cursor --windsurf --copilot
```

## Using AI Agents with Presets

Combine presets with AI agent generation:

```bash
# Use Claude to generate a configuration for Cursor
ai-rulez init "MyProject" --preset cursor --use-agent claude

# Use Gemini to generate a Claude configuration
ai-rulez init "MyProject" --preset claude --use-agent gemini
```

## Custom Configurations

If presets don't match your needs, you can:

1. Start with a preset and customize:
   ```bash
   ai-rulez init "MyProject" --preset claude
   # Then edit ai_rulez.yaml
   ```

2. Create a completely custom configuration:
   ```bash
   ai-rulez init "MyProject" --no-agent
   # Manually edit ai_rulez.yaml
   ```

3. Mix presets with custom flags:
   ```bash
   ai-rulez init "MyProject" --preset claude --cline --continue-dev
   ```

## Directory Formats

Modern tools use directory-based configurations:

- **Windsurf**: `.windsurf/` (not `.windsurfrules`)
- **Cline**: `.clinerules/`
- **Continue.dev**: `.continue/rules/`
- **Cursor**: `.cursor/rules/`

Legacy single-file formats are not supported in presets.
