## Workspace Layout

Key directories:

- `cmd/ai-rulez/main.go` boots the CLI; `cmd/commands/` holds the Cobra commands, registered in `cmd/commands/root.go`.
- `internal/` holds the service packages. The groups, with the packages to open first:
  - Load and merge: `config` (config, content tree, layers, plugin definitions), `project` (wires includes, installed skills and the `.agents` source into a load), `includes`, `skillsource`, `builtins`, `workspace` (the read view a load goes through), `agentssource` (root and nested `AGENTS.md` for `source = "agents"`), `okf` and `okfbridge`.
  - Render and write: `generator` (plan, apply, drift, clean, plugins, the managed `.gitignore` block), `generator/providers/builtin` (declarative preset specs), `generator/presets` (Go presets), `templates`, `gitignore`, `gitutil`, `agentplugins`, `ard`, `mcpcard`, `publish`.
  - Check: `lint` (`validate`, `scan`, the `AR` codes), `judge`, `review`, `evals`, `verifiers`, `doctor`, `exposure`, `areas`, `repoindex`.
  - Govern: `lockfile`, `lockrun`, `contentlock`, `approval`, `signing`, `policy`, `sbom`.
  - Serve and call out: `mcp`, `llm`, `skillsearch`, `telemetry`, `usage`.
  - Shared plumbing: `logger`, `progress`, `diag` (per-run warning collector), `render`, `runner`, `safefs`, `walkutil`, `watch`.
- `pkg/airulez/` is the public Go API (load, validate, plan or apply a generate run, lock) over a `Workspace`.
- `schema/` holds the JSON schemas for config, local config, plans and every `--format json` document.
- `docs/` and `zensical.toml` are the documentation source; `docs/llms.txt` and `docs/llms-full.txt` are generated by `scripts/docsllms`, and `docs/cli-reference.md` by `scripts/clidocs`. The `site/` output is not committed.
- `skills/` holds the skill shipped to users; `action.yml` is the composite GitHub Action that installs a verified binary.
- `release/npm` and `release/pypi` hold the JavaScript and Python wrappers around the Go binary.
- `tests/` holds `golden` (one recorded output per preset and scenario), `conformance` (standards schemas), `integration`, `e2e`, `parity` (CLI versus docs and MCP), `archlint` (no ambient authority in `internal/`), `bats` and platform scenarios.

Convenience:

- `bin/ai-rulez` is a local build used for running `generate`, `validate`, and other commands in development.
- `docs/architecture.md` describes the pipeline and has the full package map.
