# Judge

`ai-rulez judge` grades agent instruction files with a language model, from the command line alone. It needs **no
configuration file**: the model comes from flags and `AI_RULEZ_LLM_*` variables, the key from the provider's own
variable (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, ...), and neither the repository's `.ai-rulez/config.toml` nor the user
config is read. It works in a repository that has no ai-rulez setup at all, and in one that has.

It is the quick, config-free check. For dimension-by-dimension scoring with calibration and a gate, see
[Review](review.md); for the shared model access, see [LLM access](llm.md).

```console
ai-rulez judge --estimate --model openai/gpt-4o-mini   # what would be sent and what it would cost; sends nothing
ai-rulez judge --allow-llm --model openai/gpt-4o-mini  # grade AGENTS.md and .agents/*
ai-rulez judge docs/guide.md --allow-llm --model anthropic/claude-haiku-4-5 --min-score 0.8
ai-rulez judge --allow-llm --rubric rubrics/mine.md --format json
```

## What it judges

With no paths: `AGENTS.md` at any depth, and the Markdown under `.agents/` (rules, context, skills, agents, commands,
checks, domains) and `.ai-rulez/` when present. Name files or directories to judge those instead; any Markdown file
inside the project is accepted. A skill's supporting files are part of the skill, not separate targets.

- It needs a project: run it inside a git repository (or a directory that is not your home directory or `/`). In `$HOME`
  or `/` without a git repository it refuses, as `validate` does, even when paths are named. Outside git, default
  discovery (no paths) also refuses unless the directory itself has an `AGENTS.md`, an `.agents/` directory or an
  ai-rulez configuration (`.ai-rulez/config.toml`, `.config/ai-rulez/config.toml`) at its root: a folder of unrelated
  projects is not walked, name the files or directories to judge instead. Outside git the directory
  walk stops with an error past 100,000 entries, and default discovery skips directories deeper than 8 levels; a named
  path is judged at any depth.
- Files that carry the `Generated by ai-rulez` header are skipped: judge the sources, not their output. Named files and
  directories report each one as a `skipped` entry; a run with no paths leaves them out without a word.
- Paths must stay inside the project root. Symlinks are never followed; a symlinked file is reported as skipped.
- Order is deterministic (sorted by path), and a run is limited to 200 files.
- A file longer than 32 KiB is sent as its head and tail with a marker in between (`truncated` in the report); a file
  over 2 MiB, a binary file and an empty file are `skipped` entries with a reason, whether named or found below a
  directory, and one such file never stops the rest of a list. Only a file skipped for secrets is a finding (exit 2).

## Consent, egress and cost

File content leaves the machine, so every real run needs `--allow-llm`. `AI_RULEZ_LLM_ALLOW_NETWORK` is not consent
here. Before anything is sent the command prints the model and the egress host to stderr.

- The egress host must be known: it is `AI_RULEZ_LLM_BASE_URL`'s host, or the default host of `openai`, `anthropic`,
  `gemini`, `mistral`, `groq`, `deepseek`, `xai`, `openrouter` or `cohere`, or, for `bedrock`,
  `bedrock-runtime.<region>.amazonaws.com` with the region from `AWS_REGION` (else `AWS_DEFAULT_REGION`). For any
  other provider (`azure` and `vertex_ai` need a resource name or project that ai-rulez does not guess), a model with
  no `provider/` prefix and no `--provider`, or `bedrock` without a region, a real run refuses and names
  `AI_RULEZ_LLM_BASE_URL`; `--estimate` still works.
- The endpoint (`AI_RULEZ_LLM_BASE_URL`) must be `https`, or `http` to a loopback host such as `localhost`. The
  plain-http opt-in of the `[llm]` table does not apply.
- A file with secret-looking text (the `AR001` shapes: keys, tokens, private keys, `key=value` pairs) is **not sent**
  and counts as a finding. `--redact` masks the text and sends the file instead.
- The value of the API key variable (`AI_RULEZ_LLM_API_KEY_ENV`'s, and the provider's own such as `OPENAI_API_KEY`) is
  screened for like any secret: a file that contains it is not sent (or is masked with `--redact`), and the value is
  never printed. Values shorter than 8 characters are not screened. A file path is masked the same way in the prompt and
  the report.
- A `--rubric` file is sent as it is, so one with secret-looking text or the key value is refused (exit 1); `--redact`
  does not apply to it.
- A custom endpoint (`AI_RULEZ_LLM_BASE_URL`) receives no provider key unless `AI_RULEZ_LLM_API_KEY_ENV` names the
  variable that holds the key to send there.
- There is no `--max-calls`: a run is bounded by the 200-file limit, `--max-cost` and `--max-tokens`. Files are graded
  one after another, never in parallel.
- Spend is capped by `--max-cost` (default `0.25` USD). The command estimates the worst case first and refuses to start
  when it exceeds the cap, or when the model has no known price (`--max-cost 0` removes the cap; the summary still counts calls, tokens and cost). `--max-tokens` caps
  prompt plus completion tokens of the whole run.
- Prompt text and keys are never printed or logged. Every string in the output (paths, reasons, rationales, the rubric
  and model names) is masked for secrets and stripped of control characters, in text and in JSON.
- An organization policy that forbids model use ([Organization policy](policy.md)) stops a real run even without a
  config file; `--estimate` still works. `--policy` and the other `--policy-*` flags are available.
- Responses are cached in the user cache directory, keyed by project, model, rubric and file content; `--no-cache`
  turns it off.

## Estimate

`--estimate` (alias `--dry-run`, `-n`) lists the files that would be sent or skipped, the egress host and model, and the
token and worst-case cost estimate. It builds no client, needs no key and no `--allow-llm`, and exits 0.

## Rubrics

`--rubric builtin:instruction-quality` is the default: clarity, actionability, non-contradiction, scope, no secrets and
no stale commands, scored 0 to 1. `--rubric <file>` uses a Markdown file (at most 16 KiB; a symlink is refused) as the
rubric; the model scores each file 0 to 1 against it and explains the score in a sentence or two.

The file is untrusted data. It is fenced with a per-request token derived from its content, fence-looking text inside it
is defused (a space breaks every run of three or more `<` or `>`), and text in it that addresses the grader scores 0.

## Model and configuration

| Setting | Flag | Variable |
| --- | --- | --- |
| Model | `--model provider/model` | `AI_RULEZ_LLM_MODEL` |
| Provider | `--provider p` (prefix for a bare model) | `AI_RULEZ_LLM_PROVIDER` |
| Spend cap | `--max-cost usd` | `AI_RULEZ_LLM_MAX_COST_USD` |
| Token cap | `--max-tokens n` | `AI_RULEZ_LLM_MAX_TOKENS` |
| Price (USD per million tokens) | `--price-input n --price-output n` (both) | `AI_RULEZ_LLM_PRICE_INPUT_PER_MTOK`, `AI_RULEZ_LLM_PRICE_OUTPUT_PER_MTOK` |
| Endpoint | | `AI_RULEZ_LLM_BASE_URL` |
| Omit `temperature` | | `AI_RULEZ_LLM_TEMPERATURE=omit` |
| Key variable | | `AI_RULEZ_LLM_API_KEY_ENV` (default: the provider's own) |
| Timeout, retries | | `AI_RULEZ_LLM_TIMEOUT_SECONDS`, `AI_RULEZ_LLM_MAX_RETRIES` |

A flag beats its variable.

### Amazon Bedrock

`--model bedrock/<model or inference-profile id>` (for example `bedrock/global.anthropic.claude-sonnet-5-5`) needs
only `AWS_REGION`; the egress host is derived from it.

- Credentials: `AWS_BEARER_TOKEN_BEDROCK` (a Bedrock API key) or an exported `AWS_ACCESS_KEY_ID` and
  `AWS_SECRET_ACCESS_KEY` (+ `AWS_SESSION_TOKEN`) are used as they are. Otherwise `judge` resolves the default AWS
  credential chain (`AWS_PROFILE`, SSO, assume-role profiles, web identity such as `aws-actions/configure-aws-credentials`,
  container and instance roles) once, before the first call, and hands the keys to the model client for the life of the
  command. The keys are not refreshed during a run, so a run longer than the credential lifetime fails with an auth
  error. The model client itself has no credential-provider hook; this export is why the keys pass through the process
  environment. Only `judge` does this; the other model features (`eval --grader builtin`, verifiers, review) still need
  one of the explicit forms above.
- `temperature` is sent as 0 unless the model rejects it. Claude 5.x on Bedrock answers HTTP 400 ("`temperature` is
  deprecated for this model"); the request is then retried once without it and the client leaves it out from then on.
  `AI_RULEZ_LLM_TEMPERATURE=omit` leaves it out from the first request (no failed call). This applies to every
  feature that calls a model (`judge`, `eval --grader builtin`, verifiers, review).
- Price: inference-profile ids (`global.`, `us.`, `eu.`, `apac.`, ... prefix, `anthropic.` vendor prefix, `-v1:0`
  suffix) are priced as the model they name, from the built-in table, so the default `--max-cost` works. For a model the
  table does not know, give `--price-input` and `--price-output`; a price applies to the model you named. The price is
  an estimate for the cap, not a bill.

## Output and exit codes

Text: one line per file (`PASS`, `FAIL`, `SKIP`, `ERROR`), then a summary. `--format json` prints
[`schema/judge-report.schema.json`](https://github.com/Goldziher/ai-rulez/blob/main/schema/judge-report.schema.json):
`mode` (`judge` or `estimate`), `rubric`, `model`, `egress_host`, `min_score`, `files[]` (`path`, `status`, `score`,
`passed`, `rationale`, `reason`, `bytes`, `truncated`, `redacted`), `estimate` and `summary`. Neither carries file text.

| Code | Meaning |
| --- | --- |
| 0 | every judged file scored at least `--min-score` (default 0.7), or `--estimate` |
| 1 | the run could not complete: refused (no `--allow-llm`, policy, bad endpoint, over the cap), nothing to judge, a model call failed, or every selected file was skipped (the report lists each with its reason and size, and nothing is sent) |
| 2 | a file scored below `--min-score`, or was skipped for secrets |

A failure every later call would share (key, budget, consent) stops the run and marks the remaining files `error`; any
other failure is that file's alone. A run with any `error` file exits 1 so incomplete results are never mistaken for a
pass.
