# OWASP Top 10 Quick Reference
1. **Broken Access Control** — enforce authorization checks on every request
2. **Cryptographic Failures** — use strong algorithms, never roll your own crypto
3. **Injection** — parameterize queries, sanitize inputs
4. **Insecure Design** — threat model early, validate business logic
5. **Security Misconfiguration** — harden defaults, disable unnecessary features
6. **Vulnerable Components** — keep dependencies updated, audit regularly
7. **Authentication Failures** — use MFA, strong passwords, rate limiting
8. **Data Integrity Failures** — verify updates, use signed artifacts
9. **Logging Failures** — log security events, protect log data
10. **SSRF** — validate URLs, restrict outbound requests
