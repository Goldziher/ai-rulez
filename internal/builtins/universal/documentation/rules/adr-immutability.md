If the project keeps ADRs under `adrs/<area>/NNNN-short-title.md`, numbered per area from 0001: an ADR may be rewritten freely while its pull request is open. Once merged it is immutable: only status, date and links change, plus plain-fact corrections. A changed decision is a new ADR; in the old one set only `status: "superseded by ADR-<area>/NNNN"` and the date. Never rename or delete a merged ADR. Every ADR change updates its row in the ADR index (`adrs/README.md`).
