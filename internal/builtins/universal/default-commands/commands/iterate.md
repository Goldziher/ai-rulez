# Iterate

Work in iterations: perform an implementation round, followed by a critical review and adjustment pass. Rinse and repeat until the next major milestone is reached.

For each iteration:
1. **Implement**: Make progress on the current task or subtask
2. **Review**: Critically examine what you just implemented — check for correctness, edge cases, consistency, and adherence to project conventions
3. **Adjust**: Fix any issues found during review before moving forward

Continue this cycle until you reach a natural milestone (feature complete, all tests passing, etc.). Each review pass should be genuinely critical, not a rubber stamp.
