# RTK Overview
RTK (Run Task Kit) is a modern task runner and command orchestrator.
- Initialize with `rtk init` (or `rtk init -g` for global config)
- Define command groups in `.rtk.yaml`
- Execute tasks with `rtk <group> <command>`
- Supports parallel execution, dependencies, and environment management
- Provides consistent CLI interface across projects
