# Changelog entry

1. Read the top of `CHANGELOG.md` and find the `## [Unreleased]` section.
2. Pick the heading that fits the change: Added, Changed, Fixed or Removed.
3. Add one bullet in the past tense, under 100 characters, with the PR number if the user gave one.
4. Show the added bullet to the user. The task is done when exactly one new bullet exists under `[Unreleased]`.
